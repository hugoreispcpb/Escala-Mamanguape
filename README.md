# Escala Mamanguape

Sistema moderno e dinâmico de visualização de escala de plantão.

## Características

- ✅ Visualização em Calendário
- ✅ Visualização em Lista
- ✅ Busca por Profissional
- ✅ Download em PDF
- ✅ Tema claro/escuro
- ✅ Design responsivo
- ✅ Interface moderna com Tailwind CSS

## Instalação

```bash
npm install
```

## Desenvolvimento

```bash
npm run dev
```

## Build

```bash
npm run build
```

## Tecnologias

- React 18
- TypeScript
- Vite
- Tailwind CSS
- Zustand (state management)
- Wouter (routing)
- Lucide React (ícones)
- date-fns (manipulação de datas)
